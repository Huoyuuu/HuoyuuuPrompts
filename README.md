## 个人 Prompt 仓库

根目录只保留最常用、最重要的学习类 prompt：

- `苏格拉底提问法.txt`：基础苏格拉底对话模板
- `提取记忆法.txt`：文章/视频/讲义通用的提取记忆学习模板
- `对话体导学.txt`：PDF/教材逐章导学模板
- `导师prompt.txt`：初学者友好的解释与练习模板
- `大模型引导读书法.txt`：只提问、不代读的阅读引导模板
- `解题研究.txt`：解题、复盘与逆向命题分析模板

其他 prompt 已按用途归档：

- `学习类-其他/`：学习类辅助版本、旧版和变体
- `编程与代码/`：代码生成、代码题求解相关 prompt
- `阅读总结与报告/`：搜索、视频总结、论文速读、研究报告等
- `翻译与格式处理/`：翻译、LaTeX、PDF、降重、书签等
- `图像生成/`：生图、网页、draw.io 图示相关 prompt
- `元提示词/`：元 prompt、逆向 prompt、system prompt 示例
- `项目类/`：面向具体小项目的 prompt
- `破限/`：破限类 prompt 统一归档
